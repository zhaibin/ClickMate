# 打包发布指南

Windows 便携版和 macOS DMG 的发布步骤。本地编译见 [构建指南](BUILD_GUIDE.md)。

版本号只从根目录 `VERSION` 读取。脚本输出到 `releases/v<VERSION>/`。下面以当前版本 `2.2.2` 为例。

## 发版前检查

- [ ] 自动 / 手动模式、点击历史、配置保存与恢复
- [ ] 快捷键：Windows 在普通权限和注册失败两种情况下都看过；macOS 已授予辅助功能
- [ ] 自动暂停 / 恢复，以及标题栏里的检查更新
- [ ] 至少三种界面语言
- [ ] `VERSION`、`lib/version.dart`、`pubspec.yaml` 的版本号一致
- [ ] `CHANGELOG.md` 和 `README.md` 的版本标记已更新
- [ ] 在干净系统上打开发布包，而不是只在开发目录里运行

## Windows 便携版

```bat
scripts\build_release.bat
```

脚本会检查 `native\src\mouse_controller.dll`，执行 `flutter build windows --release`，复制 exe、Flutter 运行库、插件 DLL 和原生 DLL，再打 ZIP。

```
releases\v2.2.2\
├── ClickMate_v2.2.2_Portable\
│   ├── clickmate.exe
│   ├── flutter_windows.dll
│   ├── mouse_controller.dll
│   ├── *_plugin.dll
│   ├── data\
│   └── README.txt
└── ClickMate_v2.2.2_Portable.zip
```

便携版不在 exe 旁边写配置。配置、语言和日志位置见 README 的「开发与数据位置」。

目标机器需要 Windows 10 1809+ 和 Visual C++ 2022 运行库。

### 安装程序

自动更新优先下载文件名包含 `setup` 或 `installer` 的 `.exe`。便携版 ZIP 不会走静默安装。

需要 [Inno Setup](https://jrsoftware.org/isdl.php)。先打出便携版，再把该目录做成安装包，产物命名为 `ClickMate_v2.2.2_Setup.exe`。安装程序准备好后，可用 `scripts\sign_release.bat` 对指定目录中的 Setup.exe 签名。该脚本依赖本机证书和安装包路径，不是打包必需步骤。

不要把便携版再套一层单文件壳。发布物就是 ZIP，或上述安装程序。

## macOS DMG

```bash
bash scripts/build_dmg.sh
```

脚本会：

1. `flutter clean` 并 `flutter pub get`
2. 在需要时编译 `libmouse_controller.dylib`
3. `flutter build macos --release`
4. 将动态库复制到 `ClickMate.app/Contents/Frameworks/`
5. 设置 install name 为 `@executable_path/../Frameworks/libmouse_controller.dylib`
6. 生成 `releases/v2.2.2/ClickMate_v2.2.2_macOS.dmg`

用户打开 DMG，把 ClickMate 拖入「应用程序」。未签名时的「已损坏」和辅助功能授权见 [macOS 安装指南](macOS_INSTALL_GUIDE.md)。

如果必须手工组装 app，至少补上这两步：

```bash
APP="build/macos/Build/Products/Release/ClickMate.app"
mkdir -p "$APP/Contents/Frameworks"
cp native/src/libmouse_controller.dylib "$APP/Contents/Frameworks/"
install_name_tool -id "@executable_path/../Frameworks/libmouse_controller.dylib" \
  "$APP/Contents/Frameworks/libmouse_controller.dylib"
```

正式分发可再做 Developer ID 签名和公证。未签名包可以分发，但用户需要按安装指南放行。

```bash
codesign --force --deep --sign "Developer ID Application: Your Name" \
  build/macos/Build/Products/Release/ClickMate.app

codesign --force --sign "Developer ID Application: Your Name" \
  releases/v2.2.2/ClickMate_v2.2.2_macOS.dmg

xcrun notarytool submit releases/v2.2.2/ClickMate_v2.2.2_macOS.dmg \
  --apple-id "APPLE_ID" --team-id "TEAM_ID" --keychain-profile "AC_PASSWORD"
```

公证密码使用钥匙串里的 app 专用密码配置，不要写进仓库。

## 发布物对照

| | Windows ZIP | Windows Setup.exe | macOS DMG |
|--|-------------|-------------------|-----------|
| 命令 | `scripts\build_release.bat` | 便携版 + Inno Setup | `scripts/build_dmg.sh` |
| 用户操作 | 解压后运行 | 安装向导 | 拖入「应用程序」 |
| 自动更新 | 最后才选用 | 优先下载 | 下载 `.dmg` |
| 适用 | 日常分发 | 需要安装程序时 | macOS 分发 |

## 发版顺序

1. 改 `VERSION`、`lib/version.dart`、`pubspec.yaml`，写 `CHANGELOG.md`，改 `README.md` 的版本标记。
2. Windows 跑 `scripts\run_debug.bat` 和 `scripts\test_hotkey.bat`。macOS 跑 `flutter run -d macos`。
3. `scripts\build_release.bat` 与 `bash scripts/build_dmg.sh`。
4. 在干净系统安装发布包，核对快捷键、配置恢复、语言和更新入口。
5. 提交、打标签并推送：

```bash
git add -A
git commit -m "release: v2.2.2"
git tag v2.2.2
git push origin master --tags
```

把 ZIP、DMG，以及做好的 Setup.exe 上传到对应 GitHub Release。tag 必须是应用用来比较的版本号。

## 常见问题

**Windows 包打不开**

确认 ZIP 内有 `mouse_controller.dll` 和 `flutter_windows.dll`，并安装 VC++ 2022 运行库。

**macOS 提示已损坏或无法验证开发者**

见 [macOS 安装指南](macOS_INSTALL_GUIDE.md)。开发者侧用 `build_dmg.sh` 重新打包，不要只拷贝未放入 Frameworks 的 `.app`。

**macOS 快捷键无效**

用户尚未授予辅助功能，或授权后没有重启应用。

**体积**

Release 包包含 Flutter 桌面运行时，通常是几十 MB。用 `--release` 构建即可，不必再套一层压缩壳。
